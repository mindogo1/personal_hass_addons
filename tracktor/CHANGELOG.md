# Tracktor add-on

## 2.1.0

## Highlights

- **Redesigned UI** — new sidebar app shell, top-level feature routes (`/fuel`, `/insurance`, `/maintenance`, `/pollution`, `/reminders`) replacing the old `/dashboard/*` nesting, fleet-wide dashboard with rearrangeable widgets, and a new "Vintage" theme.
- **Full codebase refactor** of the app shell and route structure alongside the redesign.
- **PDF export** for maintenance logs.
- **New localizations**: German, Romanian, plus updates to Hungarian and Finnish.
